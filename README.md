# toolbar

Small self-contained tools.

- [`restaurant-order-memory/`](restaurant-order-memory/) — Seat One Clockwise: an order-memory procedure for servers (`METHOD.md`) and a phone drill that trains it (`index.html`, open directly in a browser, no build step).
- [`kusakabe-audiobook/`](kusakabe-audiobook/) — The Circle That Doesn't Need a Name: a 25-chapter Kusakabe fan fiction written for audio (`chapters/`, `full_book_tts/`), plus `scripts/make_audio.py` to voice it with Fish Audio Drama 3 through OpenRouter (settings in `.env`, see `.env.example`).
